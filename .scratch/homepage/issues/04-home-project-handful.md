# Which Projects belong on Home

Type: grilling
Status: open
Blocked by: 10

## Question

Which 3–5 Projects appear on Home, and which only appear on `/projects`?

Home shows a handful; `/projects` can show more. Employment work is not a Project. Use the inventory from [Inventory of own-name Project URLs](03-project-url-inventory.md). Wait for [How unlinkable Projects appear on a public homepage](10-unlinkable-projects.md) — most specialist-story systems have no public URL. One industry-proof card is allowed but is not the default.
