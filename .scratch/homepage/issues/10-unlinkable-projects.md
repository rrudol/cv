# How unlinkable Projects appear on a public homepage

Type: grilling
Status: open

## Question

[Inventory of own-name Project URLs](03-project-url-inventory.md) found a thin gallery-honest set: **rudol.photos**, public GitHub **tt-pii-middleware** and **frisco** (plus two archived npm libs). The systems that match the specialist story (genealogy, typewriters, career, journalism, Vera, Neuron/Hindsight, dxcs, …) are **alive on Tailscale** with **private** repos. A visitor cannot open those URLs or those GitHub pages.

How do those Projects appear on the public homepage: name and blurb with **no** URL; “tailnet” as the only affordance; only the gallery-honest three; or this spec also decides to put selected hosts/repos on the public internet?

Exposing a product to the public internet is a different change than describing it. Prefer a presentation rule for rudol.dev unless you explicitly redraw destination.
