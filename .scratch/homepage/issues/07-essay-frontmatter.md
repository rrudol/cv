# Essay URL scheme and frontmatter

Type: grilling
Status: open

## Question

What is the essay URL scheme and the required frontmatter?

Must decide: path shape (`/writing/<slug>` vs dated), required fields (title, date, related Project, syndication status), and whether an essay can exist with no related Project.

Syndication constraints from [How essays syndicate to X and Bluesky](02-syndicate-x-bluesky.md): X text is 280 weighted characters (every URL counts as 23); Bluesky is 300 graphemes and the URL is not a link unless a facet is attached. If a `hook` field exists, it has to fit both.
